ปรับค่าด้วยแถบเลื่อน ทดลองย้ายข้างอย่างสมดุล แล้วสังเกตว่าค่า x เปลี่ยนอย่างไร

🎯 เป้าหมายการเรียนรู้

นักเรียนสามารถหาคำตอบของสมการเชิงเส้นตัวแปรเดียว โดยใช้การดำเนินการเดียวกันทั้งสองข้างของสมการ และตรวจสอบคำตอบได้

สมการตัวอย่าง: ax + b = c โดย a ไม่เท่ากับ 0 ปรับค่า a, b และ c ได้จากแถบเลื่อนด้านล่าง

🧪 ทดลองปรับสมการแบบเรียลไทม์

เทคนิค: กำจัดค่าคงตัวก่อน โดยลบ b ทั้งสองข้าง จากนั้นหารทั้งสองข้างด้วย a

📝 คำถามท้ายกิจกรรม 3 ข้อ

เลือกคำตอบที่ถูกต้อง แล้วกดตรวจคำตอบในแต่ละข้อ

เฉลยพร้อมวิธีคิด
  1. 3x + 4 = 19: ลบ 4 ทั้งสองข้าง ได้ 3x = 15 แล้วหาร 3 ดังนั้น x = 5
  2. 5x − 6 = 9: บวก 6 ทั้งสองข้าง ได้ 5x = 15 แล้วหาร 5 ดังนั้น x = 3
  3. 2x + 7 = 1: ลบ 7 ทั้งสองข้าง ได้ 2x = −6 แล้วหาร 2 ดังนั้น x = −3
